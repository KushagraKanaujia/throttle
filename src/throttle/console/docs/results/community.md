# Community results

*Results shared by people running Throttle on their own hardware.*

![](../../illustrations/share.svg)

This page collects results people share with `throttle check --share`. There are none published yet. Yours can be the first.

### 1. Run a comparison

Calibrate with three checks of your current config, change one setting, check again.

### 2. Share it

```bash
throttle check --history --share
```

It prints a sanitized summary (no URLs, hosts, IPs or keys) and a link to a pre-filled GitHub issue.

### 3. Submit

Open the link, read the summary, and submit the issue. It'll be added here with your OK.
